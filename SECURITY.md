# Security Policy

## Supported Versions

Security fixes are provided for the latest published `0.x` release.

## Reporting a Vulnerability

Please report security issues privately instead of opening a public GitHub issue.

Use GitHub Security Advisories for this repository if available, or contact the
maintainer through the repository owner profile. Include the affected version,
steps to reproduce, and the impact you believe the issue has.

Do not publicly disclose a vulnerability until a fix or mitigation is available.
