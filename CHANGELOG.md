# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0 - 2026-05-02

- Initial public release.
- Added Android broadcast handling for system time, timezone, and timezone offset changes.
- Added React Native foreground listener support.
- Added Headless JS task delivery support.
- Added `getCurrentTimeContext()` for reading the current timezone, UTC offset, and timestamp.
